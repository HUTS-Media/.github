## What we build

**HUTS Media** is one workspace for releasing music and getting paid for it:

- **Distribution.** One release goes in (audio, artwork, metadata, delivery terms) and goes out to Spotify, Apple Music, YouTube Music, Amazon Music, TikTok, Deezer and more, with a live status per store.
- **Royalties.** Contracts, statement runs, self-billing invoices and a running balance per payee.
- **Artist Portal.** Artists and labels see their catalog, statements and payments in one place.
- **Catalog access for AI assistants.** An MCP server lets Claude and other clients read the catalog and prepare release imports.

We also build tools around the music business: music-marketing software (lyric videos, ad campaigns, playlists), smart links for every streaming platform, and audio utilities for stems. Our sister company **HMG** is an independent record label focused on Dance and Pop.
